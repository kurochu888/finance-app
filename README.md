# 財務管理 App

手機用的個人財務 app:記帳、預算、資產負債、淨資產走勢,以及房貸槓桿試算。
所有數字都是自己填的,**資料不會上傳到任何伺服器**(Claude Artifact 版除外,那份存在你自己的 Claude 帳號下)。

## 線上版

**https://kurochu888.github.io/finance-app/**

用手機瀏覽器打開網址即可。
iPhone:分享 →「加入主畫面」;Android:選單 →「安裝應用程式」。
安裝後有 app 圖示,離線也能開。

## 功能

| 分頁 | 內容 |
|---|---|
| 📊 總覽 | 淨資產與走勢、投資部位摘要、當月收支、支出類別;槓桿警訊;匯出匯入與每日備份還原 |
| 🏦 資產 | 資產與負債明細、佔比 |
| ⚡ 槓桿 | 部位損益、曝險與風險、走勢圖、買賣紀錄、持股市值(可從證交所帶入收盤價)、動用觸發點與動用紀錄、利息試算、撤退門檻、壓力測試 |
| 📒 記帳 | 收支記錄,可就地修改與刪除;類別下拉選,可自行新增 |

## 開發

程式碼只有一份:`app.template.html`。改完之後跑:

```sh
python3 build.py        # 產生下面三個版本
python3 make_icons.py   # 只有要改圖示時才需要
git add -A && git commit -m "..." && git push   # 推上去,Pages 會自動更新
```

Pages 從 `main` 分支的 `/docs` 目錄發佈。

| 產出 | 用途 | 資料存哪 |
|---|---|---|
| `finance_app.html` | 獨立單檔,雙擊即用 | 該裝置瀏覽器 localStorage |
| `docs/` | GitHub Pages 的 PWA,可安裝、離線可用 | 該裝置瀏覽器 localStorage |
| `finance_app_artifact.html` | Claude Artifact 版 | Claude 雲端,跨裝置同步 |

三個版本共用同一份程式;差別只在存檔方式與外層包裝。
雲端存檔是可插拔的:Artifact 版用平台內建 db,網頁版用 Firebase(`firebase-sync.js`),
兩者都連不上就退回 localStorage,功能不受影響。
`app.template.html` 裡的 `/*STORAGE_NOTE*/` 由 `build.py` 依版本置換。

## 自動化的部分

- **收盤價**:槓桿頁可從臺灣證交所公開資訊帶入 00631L、00675L 收盤價與加權指數,
  每小時最多抓一次。是收盤價不是即時報價;Artifact 版因 CSP 限制不提供。
- **歷史最高市值**:動用桶金之前自動記錄新高,動用後凍結成撤退目標。
- **槓桿利息**:每月自動在記帳產生一筆「房貸利息」支出,已記過的月份不會重複;
  你把那筆刪掉也不會被補記。可在槓桿頁關閉。
- **持股股數**:一旦有買賣紀錄,股數由紀錄自動加總,不用手動維護。
- **每日備份**:每天第一次開啟時存一份快照。雲端保留 30 份;本機只保留 7 份,
  因為 localStorage 通常只有 5MB,備份佔太多會讓主資料存不進去。
  真的寫不下時會先刪最舊的備份,確保主資料一定存得住。
- **走勢圖**:槓桿頁的部位市值與損益走勢用每日快照(每天開啟或按更新報價時記一筆,
  保留最近 1000 個交易日),可切 1 個月 / 3 個月 / 1 年 / 全部;資料不足兩筆時退回每月快照。
  總覽的淨資產走勢用每月快照,中間沒開過 app 的月份留空,間隔才不會失真。

## 損益怎麼算

買賣紀錄用**加權平均成本法**,支援買進、賣出、配息三種。每筆買進要標明資金來源
(自有 / 房貸),因為槓桿的重點就在自有資金與總投入的報酬率差距。配息計入已實現
損益,不影響持股成本與股數。

```
未實現損益 = 目前市值 − 剩餘持股成本
已實現損益 = 賣出淨額 − 賣出部分的平均成本(配息也算在這裡)
整體損益   = 未實現 + 已實現 − 累積借款利息
淨投入     = 累計自有投入 − 賣出回收 − 配息      還放在裡面的錢
```

報酬率用 **XIRR(現金流內部報酬率)**,把每一筆買進、賣出、配息、房貸還款與
每月利息按**實際日期**折現,最後加上「今天結清可以拿回的錢」(市值 − 借款餘額)。
不定期加碼時,上個月才投入的錢不會被當成放了兩年。

累積利息從各桶金的「動用日期」算到今天,**依實際餘額分段計算** —— 記了還款之後,
只對剩下的部分繼續算。撤退門檻的每年 8% 也用同一套累積方式。不扣利息的話,
槓桿部位看起來會永遠比實際好。

借款餘額 = 各桶動用金額 − 已還款。全部還清後不再計息,撤退訊號也會關閉,
但動用紀錄與還款歷史都保留。

## 曝險怎麼看

標的可自行增減,每檔設定自己的槓桿倍數(正2 填 2、一般股票填 1),
曝險與壓力測試都照各自的倍數換算:

```
實質市場曝險 = Σ(各標的市值 × 該標的槓桿倍數)
曝險比例     = 實質市場曝險 ÷ (部位淨值 + 理財型房貸總額度)
部位淨值     = 部位市值 − 借款餘額            自己的錢
槓桿倍數     = 部位市值 ÷ 部位淨值
```

分母是「自己的錢 + 還能借的火力」,不是淨資產 —— 房子與現金不會拿去接刀,
真正的上限是額度。

分母用**部位淨值**而不是部位市值:已借出的錢同時存在於部位與額度中,
用市值會把它算兩次,分母灌水、比例看起來比實際安全。改用淨值之後,
額度用得越多分母越接近自有資金,比例會誠實地升高。

## 雲端同步(選用)

預設資料只存在各自的裝置。要跨裝置同步,照 [SETUP-FIREBASE.md](SETUP-FIREBASE.md)
設定 Firebase + Google 登入:資料存在 Firestore,安全規則限定只有本人讀得到自己的資料。
`firebase-config.js` 的 `apiKey` 留空時,app 會維持純本機模式。

## 免責

槓桿分頁的計算都是簡化試算(未計入正2 ETF 的波動耗損與追蹤誤差),
不構成投資或貸款建議。實際利率與額度以銀行核定為準。
